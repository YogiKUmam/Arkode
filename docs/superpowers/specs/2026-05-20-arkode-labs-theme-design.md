## Brand Direction

Use the Clean Tech Premium direction: light, structured, professional, and technology-driven. The interface should feel reliable for business buyers while still carrying a software engineering identity.

## Visual System

- Brand name: Arkode Labs
- Tagline: Membangun software yang rapi, andal, dan siap berkembang.
- Primary colors: Navy Dark `#0B1020`, Electric Blue `#2563EB`, Cyan `#22D3EE`
- Supporting colors: Soft Blue `#EFF6FF`, Slate Black `#111827`, White `#FFFFFF`
- Typography direction: bold geometric headings, calm readable body text
- UI style: clean cards, thin borders, grid layouts, outline icons, dashboard mockup accents

## Website Changes

Public pages should use Arkode Labs copy from the company profile. Services, process, pricing, and blog content should reflect the documented offering: company profile websites, landing pages, web applications, dashboard systems, UI/UX, and maintenance.

## Admin Changes

The admin dashboard keeps the existing local CMS behavior for case studies and blog posts. Its UI should visually match the public site with Arkode Labs branding, colors, and content-studio language.
